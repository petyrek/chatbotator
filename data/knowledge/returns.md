# Returns & refunds

Last updated: 26 October 2026. These are fictional policies for the TrailSupply learning project.

## Return window

- The delivery date counts as day 0. A standard return requested on or before day 30 is in time; day 31 or later is too late.
- Example: for an order delivered on 26 September, the last day to request a standard return is 26 October.
- Orders that have not been delivered yet cannot be returned. See Order changes in the shipping policy for cancellation.

## Condition

- Items must be unused, with original tags attached.
- Unused means the item has not been taken outdoors or used for its purpose: a backpack not worn outdoors, a tent not pitched outdoors, a bottle not filled with a drink.
- Opening the packaging, or trying an item on indoors, does not make it used.

## Partial returns

- You may return some items from an order and keep the rest. Each returned item is assessed on its own.
- For an item with quantity greater than 1, each unit is assessed on its own.

## Refunds

- A standard return refunds the paid price of each accepted item, minus one €6 return shipping charge per return request, however many items it contains.
- Original outbound shipping charges are not refunded for a standard return. Free outbound shipping is never charged back, even if a partial return brings the kept items below €100.
- Refunds are issued after inspection, to the original payment method, within 5–10 business days.
- Eligibility does not mean a refund has already been issued. An action requires explicit confirmation.

## Defective items

- A suspected manufacturing defect follows the warranty process, even for an item that is used or outside the standard return window.
- Defective-item return shipping is free.
- Do not promise a refund for a defect before review. A support specialist must inspect the claim.
