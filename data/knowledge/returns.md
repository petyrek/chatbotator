# Returns & refunds

Last updated: 26 October 2026. These are fictional policies for the TrailSupply learning project.

## Standard returns

- Request a standard return within 30 calendar days of delivery, including day 30.
- Items must be unused, with original tags attached. Opening the packaging alone does not make an item used.
- A backpack that has been worn outdoors is used and is not eligible for a standard return.
- Customer-paid standard return shipping costs €6. Defective-item return shipping is free.

## Refunds

- A standard return refunds the returned item's paid price after inspection, minus the €6 return shipping charge.
- Original outbound shipping charges are not refunded for a standard return.
- Approved refunds are sent to the original payment method within 5–10 business days after inspection.
- Eligibility does not mean a refund has already been issued. An action requires explicit confirmation.

## Defective items

- A suspected manufacturing defect follows the warranty process, even outside the standard return window.
- Do not promise a refund for a defect before review. A support specialist must inspect the claim.
